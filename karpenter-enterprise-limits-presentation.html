WALL 02

Consolidation Breaks Stateful Workloads

Standard eviction disrupts pods — Container Live Migration moves them live
⚠
Standard Eviction
  • Pod terminated — in-flight requests dropped
  • State lost — local storage wiped on node drain
  • Connection pools reset — cold-start latency spikes
  • Disruption budget exhausted under heavy consolidation
✓
Container Live Migration
  • Pod checkpointed — memory + state captured
  • Restored on new node — no cold start
  • Zero downtime — connections preserved
  • Stateful-safe — works with databases, caches, queues
CLM Labels · pod annotations
metadata:
  annotations:
    clm.cast.ai/enabled: "true"

  terminationGracePeriodSeconds: 300▊

ARCHITECTURE

CRD-First Design

Everything is a Kubernetes Custom Resource — gitops-ready, declarative, auditable
NodePool v1 · CRD manifest
apiVersion: karpenter.sh/v1
kind: NodePool
metadata:
  name: production
spec:
  template:
    metadata:
      labels:
        team: platform
        env: prod
    spec:
      requirements:
        - key: node.kubernetes.io/instance-type
          operator: In
          values: ["c6i.large", "m6i.large"]
        - key: karpenter.sh/capacity-type
          operator: In
          values: ["spot", "on-demand"]
      nodeClassRef:
        group: karpenter.k8s.aws
        kind: EC2NodeClass
        name: default
  limits:
    cpu: "1000"
    memory: 4000Gi▊
